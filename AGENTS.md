## Agent skills

### Issue tracker

Los issues viven en GitHub Issues de este repo (vía `gh` CLI). See `docs/agents/issue-tracker.md`.

### Triage labels

Etiquetas canónicas por defecto (needs-triage, needs-info, ready-for-agent, ready-for-human, wontfix). See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: un `CONTEXT.md` + `docs/adr/` en la raíz. See `docs/agents/domain.md`.

### Diseño visual

Antes de construir o modificar cualquier pantalla, lee `DESIGN.md`, que es el sistema visual "Comprobante de pieza". El contexto del producto está en `PRODUCT.md`, y la maqueta de referencia en `design/maqueta/` (ficha y carga).
