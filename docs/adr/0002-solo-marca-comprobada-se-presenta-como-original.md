# Solo una marca comprobada se presenta como "Original"

Las marcas reconocibles suben el precio de una pieza, pero una sola falsificación vendida como original puede costar más confianza que el margen que genera (estudio de mercado, sección 15). Decidimos clasificar la autenticidad de cada pieza en tres niveles (marca comprobada, marca atribuida, sin marca) y mostrar "Original" únicamente para las comprobadas; una marca atribuida se publica con su marca y la aclaración "autenticidad no verificada". No se relaja esta regla para subir precios o conversión.

Aunque la operadora puede ocultar atributos de una pieza en su ficha, **marca y autenticidad se publican juntas o no se publican**: no se permite mostrar la marca ocultando que no está verificada.
